# AI Task Generator (Flask + Gemini)

This project is an interactive AI-powered web application that generates insights based on user input.

## 📸 Demo

### 🖥️ User Interface
![App UI](app-ui.png)

### ⚙️ Backend / API
![Backend](backend.png)

## 🚀 Features

- Generate AI-powered task ideas from a topic
- Clean and responsive interface
- Simple Flask backend integration
- Gemini API support
- Deployed on Render

## 🛠️ Tech Stack
- Python
- Flask
- JavaScript
- HTML / CSS
- Gemini API
- LiteLLM
- Render

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
```
🔐 Environment Variables

Create a .env file:

GEMINI_API_KEY=your_api_key_here

📌 Example Use

Input:
"AI in education"

Output:

Personalized learning
Automated tasks
Enhanced accessibility
